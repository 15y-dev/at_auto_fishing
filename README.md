# テンプレートマッチングプログラム

画面上の指定範囲内で、テンプレート画像と一致する場所を検索するPythonプログラムです。

## 📋 機能

- 指定した画面範囲を定期的にキャプチャ
- 複数のテンプレート画像（01.png～04.png）を検索
- グレースケール変換による高精度マッチング
- テンプレートが1つでも見つかったら即座に終了
- 見つかった位置の座標と信頼度を表示

## 🚀 使い方

### 1. 初回セットアップ

仮想環境に必要なライブラリをインストールします：

```bash
.venv\Scripts\activate
pip install -r requirements.txt
```

### 2. 設定

`main.py` の上部にある設定を編集します：

```python
# キャプチャ対象プログラムの実行ファイル名（プロセス名）
# 指定したプロセスのウィンドウ左上（クライアント領域）を原点(0,0)とした
# 相対座標で検索範囲を指定する
TARGET_PROCESS_NAME = "game.bin"

# 検索範囲の設定（対象ウィンドウ左上からの相対座標）
REGION_TOP = 710       # 上端のY座標（相対値・共通）
REGION_WIDTH = 50      # 幅（共通）
REGION_HEIGHT = 50     # 高さ（共通）

SEARCH_REGIONS_LEFT = [650, 750, 850, 940, 1035, 1125, 1220]

# テンプレート画像のリスト
TEMPLATES = ['01.png', '02.png', '03.png', '04.png']

# マッチング閾値 (0.0～1.0、高いほど厳密)
THRESHOLD = 0.8

# 検索間隔（秒）
INTERVAL = 1.0
```

**ポイント:** `SEARCH_REGIONS_LEFT` / `REGION_TOP` などの座標は、画面全体の絶対座標ではなく、
`TARGET_PROCESS_NAME` で指定した実行ファイルのウィンドウの**左上（クライアント領域）を原点(0,0)**
とした相対座標です。対象ウィンドウを移動しても、プログラムが自動的にウィンドウ位置を検出し、
検索範囲を追従させます。

### 3. 実行方法


#### 管理者権限で実行（推奨）
```bash
run_admin.bat
```
ダブルクリックすると自動的に管理者権限で起動します。

**対象プログラムが管理者権限で動作している場合、管理者権限は必須です。**
UIPI（User Interface Privilege Isolation）により、低い整合性レベルのプロセスからは
入力を送れないためです。

### 4. 停止方法

プログラムを途中で停止したい場合は、`Ctrl + C` を押してください。

## 🎮 数字キーの送信

テンプレートが見つかると、`NUMBER_MAPPING` に従った数字（`01.png`→`1` … `04.png`→`4`）を
`SendInput` API でキー入力として送信します。追加のハードウェアは不要です。

- 仮想キーコードではなく**スキャンコード**（`KEYEVENTF_SCANCODE`）で送信します。
  より低レベルな表現であり、DirectInput のようにスキャンコードを直接参照する
  プログラムでも認識されやすいためです
- 送信する数字を変えたい場合は `main.py` の `NUMBER_MAPPING` を編集してください
- キーの押下時間は `KEY_PRESS_DURATION`（既定 0.05 秒）で調整します。
  対象プログラムの入力ポーリング間隔によって取りこぼされる場合は長くしてください

### 動作確認

キー入力がOSに届いているかは、以下で確認できます。

```bash
python test_sendinput.py
```

`GetAsyncKeyState` で押下を検出するため、メモ帳を開いたりウィンドウを
切り替えたりする必要はありません。

## ⚙️ 設定項目の説明

### TARGET_PROCESS_NAME（対象プログラム）
- キャプチャ対象とするプログラムの実行ファイル名（例: `"game.bin"`）
- プログラムはこのプロセス名を持つ可視ウィンドウを自動で検索し、
  そのウィンドウのクライアント領域左上を原点(0,0)として以下の検索範囲を解釈します
- 対象ウィンドウが見つからない場合はエラーを表示して終了します
- 対象ウィンドウを移動しても、実行中は自動的に追従します

### REGION_TOP / REGION_WIDTH / REGION_HEIGHT / SEARCH_REGIONS_LEFT（検索範囲）
対象ウィンドウ左上からの相対座標で、検索する範囲を指定します。
- `REGION_TOP`: 各範囲共通の上端Y座標（相対値・ピクセル）
- `REGION_WIDTH` / `REGION_HEIGHT`: 各範囲共通の幅・高さ（ピクセル）
- `SEARCH_REGIONS_LEFT`: 範囲ごとに異なる左端X座標（相対値・ピクセル）のリスト（左から順に登録）

### THRESHOLD（マッチング閾値）
- `0.0～1.0` の範囲で指定
- 高い値（例：0.9）= より厳密にマッチング（誤検出が減る）
- 低い値（例：0.7）= より緩くマッチング（検出しやすい）
- 推奨値：`0.8`

## 🔧 トラブルシューティング

### テンプレートが見つからない場合
1. `THRESHOLD` の値を下げてみる（例：0.7）
2. 検索範囲が正しいか確認する
3. テンプレート画像が正しい場所にあるか確認する
4. `USE_GRAYSCALE` を `False` に変更してみる

### プログラムが起動しない場合
1. 仮想環境が正しくセットアップされているか確認
2. 必要なライブラリがインストールされているか確認：
   ```bash
   .venv\Scripts\activate
   pip install -r requirements.txt
   ```

### 画面キャプチャができない場合
- 管理者権限で実行してみる（`run_admin.bat` を使用）

### キー入力が届かない場合
1. `run_admin.bat` で管理者権限で起動する（対象プログラムが管理者権限で
   動作している場合は必須）
2. `python test_sendinput.py` でOSに届いているか切り分ける

詳しくは [TROUBLESHOOTING.md](TROUBLESHOOTING.md) を参照してください。

## 📝 必要なライブラリ

- `opencv-python`: 画像処理・テンプレートマッチング
- `numpy`: 数値計算
- `mss`: 高速スクリーンキャプチャ
- `Pillow`: 画像処理補助
- `pywin32`: ウィンドウ検索・座標取得

キー入力の送信には Windows の `SendInput` API を直接使うため、
追加のライブラリは不要です（`ctypes` で呼び出しています）。
