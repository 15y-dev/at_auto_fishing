# テンプレートマッチングプログラム

画面上の指定範囲内で、テンプレート画像と一致する場所を検索するPythonプログラムです。

## 📋 機能

- 指定した画面範囲を定期的にキャプチャ
- 複数のテンプレート画像（01.png～04.png）を検索
- グレースケール変換による高精度マッチング
- テンプレートが1つでも見つかったら即座に終了
- 見つかった位置の座標と信頼度を表示

## 🚀 使い方

### 1. 初回セットアップ

仮想環境に必要なライブラリをインストールします：

```bash
.venv\Scripts\activate
pip install -r requirements.txt
```

### 2. 設定

`main.py` の上部にある設定を編集します：

```python
# 検索範囲の設定
SEARCH_REGION = {
    "top": 100,      # 上端のY座標
    "left": 100,     # 左端のX座標
    "width": 800,    # 幅
    "height": 600    # 高さ
}

# テンプレート画像のリスト
TEMPLATES = ['01.png', '02.png', '03.png', '04.png']

# マッチング閾値 (0.0～1.0、高いほど厳密)
THRESHOLD = 0.8

# 検索間隔（秒）
INTERVAL = 0.5

# グレースケール変換を使用（マッチング精度向上）
USE_GRAYSCALE = True
```

### 3. 実行方法

#### 方法A: 通常実行
```bash
run.bat
```
ダブルクリックで実行できます。

#### 方法B: 管理者権限で実行（推奨）
```bash
run_admin.bat
```
ダブルクリックすると自動的に管理者権限で起動します。

### 4. 停止方法

プログラムを途中で停止したい場合は、`Ctrl + C` を押してください。

## ⚙️ 設定項目の説明

### SEARCH_REGION（検索範囲）
画面のどの部分を検索するかを指定します。
- `top`: 検索範囲の上端Y座標（ピクセル）
- `left`: 検索範囲の左端X座標（ピクセル）
- `width`: 検索範囲の幅（ピクセル）
- `height`: 検索範囲の高さ（ピクセル）

### THRESHOLD（マッチング閾値）
- `0.0～1.0` の範囲で指定
- 高い値（例：0.9）= より厳密にマッチング（誤検出が減る）
- 低い値（例：0.7）= より緩くマッチング（検出しやすい）
- 推奨値：`0.8`

### USE_GRAYSCALE（グレースケール変換）
- `True`: グレースケール変換を使用（推奨）
  - 色情報のノイズを除去し、マッチング精度が向上
- `False`: カラーのままマッチング
  - 色が重要な場合に使用

## 🔧 トラブルシューティング

### テンプレートが見つからない場合
1. `THRESHOLD` の値を下げてみる（例：0.7）
2. 検索範囲が正しいか確認する
3. テンプレート画像が正しい場所にあるか確認する
4. `USE_GRAYSCALE` を `False` に変更してみる

### プログラムが起動しない場合
1. 仮想環境が正しくセットアップされているか確認
2. 必要なライブラリがインストールされているか確認：
   ```bash
   .venv\Scripts\activate
   pip install -r requirements.txt
   ```

### 画面キャプチャができない場合
- 管理者権限で実行してみる（`run_admin.bat` を使用）

## 📝 必要なライブラリ

- `opencv-python`: 画像処理・テンプレートマッチング
- `numpy`: 数値計算
- `mss`: 高速スクリーンキャプチャ
- `Pillow`: 画像処理補助
