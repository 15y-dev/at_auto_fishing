# テンプレートマッチングプログラム

対象プログラムのウィンドウ内を定期的にキャプチャし、テンプレート画像と一致する場所を
検出して、対応する数字キーを自動入力する Python プログラムです。

## 📋 機能

- 対象プロセスのウィンドウを自動検出し、その位置に追従して範囲をキャプチャ
- 複数の検索範囲（左から順に7箇所）を1回のキャプチャから切り出して判定
- 複数のテンプレート画像（01.png～04.png）をグレースケールでマッチング
- 一致したテンプレートに対応する数字キーを `SendInput` API で送信
- `Ctrl + C` で停止するまで繰り返し動作

## 🚀 使い方

### 1. 初回セットアップ

仮想環境に必要なライブラリをインストールします。

```bash
.venv\Scripts\activate
pip install -r requirements.txt
```

### 2. 設定

`main.py` の上部にある設定を編集します。

```python
# キャプチャ対象プログラムの実行ファイル名（プロセス名）
TARGET_PROCESS_NAME = "game.bin"

# 検索範囲の設定（対象ウィンドウ左上からの相対座標）
REGION_TOP = 605       # 上端のY座標（相対値・共通）
REGION_WIDTH = 50      # 幅（共通）
REGION_HEIGHT = 50     # 高さ（共通）

SEARCH_REGIONS_LEFT = [330, 430, 530, 620, 715, 805, 900]

# テンプレート画像のリスト
TEMPLATES = ['01.png', '02.png', '03.png', '04.png']

# テンプレート名 → 送信する数字
NUMBER_MAPPING = {'01.png': '1', '02.png': '2', '03.png': '3', '04.png': '4'}

THRESHOLD = 0.8   # マッチング閾値 (0.0～1.0、高いほど厳密)
INTERVAL = 1.0    # 検索間隔（秒）
```

**ポイント:** 座標は画面全体の絶対座標ではなく、`TARGET_PROCESS_NAME` で指定した
実行ファイルのウィンドウの**左上（クライアント領域）を原点(0,0)** とした相対座標です。
対象ウィンドウを移動しても、プログラムが自動的にウィンドウ位置を検出して追従します。
既定値は 1280x1024 のウィンドウを想定しているため、サイズが異なる場合は調整してください。

### 3. 実行方法

```bash
run_admin.bat
```

ダブルクリックすると自動的に管理者権限で起動します。

**対象プログラムが管理者権限で動作している場合、管理者権限は必須です。**
UIPI（User Interface Privilege Isolation）により、低い整合性レベルのプロセスからは
入力を送れないためです。

### 4. 停止方法

`Ctrl + C` を押してください。検索回数と経過時間が表示されて終了します。

## 🎮 数字キーの送信

テンプレートが見つかると、`NUMBER_MAPPING` に従った数字（`01.png`→`1` … `04.png`→`4`）を
`SendInput` API でキー入力として送信します。追加のハードウェアやライブラリは不要です。

- 仮想キーコードではなく**スキャンコード**（`KEYEVENTF_SCANCODE`）で送信します。
  より低レベルな表現であり、DirectInput のようにスキャンコードを直接参照する
  プログラムでも認識されやすいためです
- キーの押下時間は `KEY_PRESS_DURATION`（既定 0.05 秒）で調整します。
  対象プログラムの入力ポーリング間隔によって取りこぼされる場合は長くしてください
- 送信後の待機時間は `BUTTON_PRESS_INTERVAL`（既定 0.1 秒）です

## ⚙️ 設定項目の説明

### TARGET_PROCESS_NAME（対象プログラム）
- キャプチャ対象とするプログラムの実行ファイル名（例: `"game.bin"`）
- このプロセス名を持つ可視ウィンドウを自動で検索し、クライアント領域左上を
  原点(0,0)として検索範囲を解釈します
- 起動時に見つからなくても終了せず、ループ内で再検索を続けます（起動待ちに対応）

### REGION_TOP / REGION_WIDTH / REGION_HEIGHT / SEARCH_REGIONS_LEFT（検索範囲）
- `REGION_TOP`: 各範囲共通の上端Y座標（相対値・ピクセル）
- `REGION_WIDTH` / `REGION_HEIGHT`: 各範囲共通の幅・高さ（ピクセル）
- `SEARCH_REGIONS_LEFT`: 範囲ごとに異なる左端X座標（相対値・ピクセル）のリスト（左から順に登録）

### THRESHOLD（マッチング閾値）
- `0.0～1.0` の範囲で指定
- 高い値（例：0.9）= より厳密にマッチング（誤検出が減る）
- 低い値（例：0.7）= より緩くマッチング（検出しやすい）
- 推奨値：`0.8`

### DEBUG（デバッグモード）
- `True` にすると毎回の検索状況と、信頼度0.5超の切り出し画像
  （`debug_region_*.png`）を出力します

## 🔧 トラブルシューティング

### テンプレートが見つからない場合
1. `THRESHOLD` の値を下げてみる（例：0.7）
2. `DEBUG = True` にして、切り出し画像と信頼度を確認する
3. 対象ウィンドウのサイズに合わせて検索範囲の座標を調整する

### キー入力が届かない場合
- `run_admin.bat` で管理者権限で起動する（対象プログラムが管理者権限で
  動作している場合は必須）

### 画面キャプチャができない場合
- 管理者権限で実行してみる（`run_admin.bat` を使用）

## 📝 必要なライブラリ

- `opencv-python`: 画像処理・テンプレートマッチング
- `numpy`: 数値計算
- `mss`: 高速スクリーンキャプチャ
- `pywin32`: ウィンドウ検索・座標取得

キー入力の送信には Windows の `SendInput` API を直接使うため、
追加のライブラリは不要です（`ctypes` で呼び出しています）。
